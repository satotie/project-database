# Shoe Shop 👟

ร้านขายรองเท้าออนไลน์ — โปรเจกต์วิชาฐานข้อมูล (Laravel + Livewire + MySQL)

E-commerce web app with two roles (**customer** and **staff**); guests can browse the catalog.
The UI is in Thai, prices in Thai Baht.

- Database design (ER / EER / relational mapping): [`docs/database.md`](docs/database.md)
- Stack: Laravel 13, Livewire 4 starter kit (Fortify auth, Flux UI, Tailwind 4), MySQL 8.4, Laravel Sail

## Setup (for teammates)

Requirements: Docker Desktop (on Windows use WSL2 Ubuntu and keep the project inside the WSL filesystem).

```bash
# 1. Clone
git clone <repo-url> shoe-shop
cd shoe-shop

# 2. Install PHP dependencies without PHP on your machine
docker run --rm \
    -u "$(id -u):$(id -g)" \
    -v "$(pwd):/var/www/html" \
    -w /var/www/html \
    laravelsail/php84-composer:latest \
    composer install --ignore-platform-reqs

# 3. Environment file (already set up for Sail's MySQL)
cp .env.example .env

# 4. Start containers (app + mysql)
./vendor/bin/sail up -d

# 5. App key
./vendor/bin/sail artisan key:generate

# 6. Front-end assets
./vendor/bin/sail npm install
./vendor/bin/sail npm run build

# 7. Database with demo data
./vendor/bin/sail artisan migrate:fresh --seed

# 8. Public storage link (product images, payment slips)
./vendor/bin/sail artisan storage:link
```

Open <http://localhost>.

Always run commands through Sail (`./vendor/bin/sail …`), never php/composer/npm on the host.

Useful commands:

```bash
./vendor/bin/sail artisan test              # run the test suite
./vendor/bin/sail artisan migrate:fresh --seed   # reset demo data
./vendor/bin/sail npm run dev               # Vite dev server with hot reload
./vendor/bin/sail down                      # stop containers
```

## Features

### Customer / public
- **Home** — hero, new arrivals, shop by brand / category, call-to-action
- **Products** — search, filter by brand, category, gender, price range, size in stock; sort by newest, price, rating; pagination
- **Product detail** — image gallery, size selector with stock per size (out-of-stock disabled), add to cart, rating summary and reviews
- **Register / Login** (phone on register, no email verification; deactivated accounts cannot log in)
- **Cart** — change quantity (limited by stock), remove, subtotal, free-shipping hint
- **Checkout** — shipping method (Standard ฿50 / free from ฿3,000, Express ฿100, Pickup free), address book or new address, coupon, full summary; order is placed in a DB transaction with row locks
- **Payment** — fake bank account, upload transfer slip (JPG/PNG ≤ 4MB), re-upload after a rejection
- **My orders** — status filter, detail with timeline, tracking number, cancel while unpaid (stock is restored), link to review delivered products
- **Member info** (`/account`) — profile, member since, total orders / total spent, address book CRUD
- **Reviews & rating** — only after a delivered order, one per product (editable)

### Staff (`/staff`)
- **Dashboard** — today's revenue, pending payments, orders to ship, low-stock sizes (≤ 3), customers, latest orders
- **Products** — search/filter, create/edit with multiple image upload and inline sizes & stock; delete (disabled instead if it has orders)
- **Brands & categories** — CRUD
- **Orders** — filter/search, slip preview, approve/reject payment, status changes (only allowed transitions), tracking number, copy a Thai notification message for the customer
- **Users** — search, orders count & total spent, activate/deactivate, change role (not yourself)
- **Coupons** — CRUD, percent discount, all products or selected products, min order, usage limit, validity period, times used
- **Sales report** — date range, revenue, orders, average order value, discounts, revenue per day chart (Chart.js), top 10 products, revenue by brand and by category, CSV export
